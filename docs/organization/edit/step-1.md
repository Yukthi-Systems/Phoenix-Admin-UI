### Edit Organization

Click Edit Organization to update an existing organization. It's a 3-step form that covers much the same ground as Adding a New Organization (section 2.4), minus the preview step and a couple of fields that don't apply once an organization already exists. Unlike the Add wizard, the Update Organization button appears at the bottom of every step here, not just the last one — you can save your changes as soon as you're done, without stepping through the rest.

**Step 1 of 3 — Organization Details**

Same fields as Organization Details in section 2.4 — Organization Name, Organization Type, Select Parent Organization and Additional Information (Description, Website, GST Number) — plus the Services Configuration toggles for Email, Chat and File Service. A couple of differences from the Add wizard:

| Field                       | Difference from Add                                                                                                                                    |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Organization Name           | Editable here too. Changing it renames the organization when you save — the same effect as using Rename Organization from the list page (section 2.2). |
| Allocated Quota (GB)        | Not shown here — change storage using Manage Space from the row actions menu instead (section 2.2).                                                    |
| Email Identities Allocation | Not shown here — change this using Manage Identities from the row actions menu instead (section 2.2).                                                  |
| Organization Active         | Not shown here — use Deactivate from the row actions menu to turn the organization off instead.                                                        |

> **Note:** A service toggle (Email, Chat or File) is disabled and greyed out if that service isn't available to this organization's parent — turn it on for the parent first.
