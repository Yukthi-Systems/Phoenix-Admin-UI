### Step 2 of 4 — Branches

![Step 2: Branches.](../../images/org-step2-branches.png)

*Step 2: Branches.*

A branch is simply an office or location that belongs to this organization. You must add at least one before you can continue — if you try to move on without one, the panel will simply remind you to add a branch first.

| Field | What it means |
| --- | --- |
| Branch Name | A short name for this office, e.g. "Head Office" or "Mumbai Branch". |
| Address Line 1 / 2 | The street address. Line 1 is required, Line 2 is for extra details like a floor or building name. |
| City / State / Country / Pincode | The rest of the address, filled in normally. |

Fill in the details and click + Add Branch to save it to the list below. Add more than one if the organization has more than one office.
