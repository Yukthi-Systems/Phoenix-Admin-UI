**Step 2 of 2 — Personal Details.**

The same fields as Step 3 of Adding a New Admin User (Additional Details), grouped here into Personal Information, Preferences and Address Information sections instead of one flat list — First Name, Last Name, Alternate Email (labeled Other Email here), Timezone, Locale, Address, City, State/Province, Country and Zip Code.

> **Note:** First Name, Last Name and Timezone are required here. In the Add wizard's Step 3, everything on the step is optional except Timezone — but once an admin user exists, their first and last name must be filled in too.
