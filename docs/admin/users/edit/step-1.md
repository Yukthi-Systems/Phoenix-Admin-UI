### Edit User

Click Edit User (from the row actions menu on the Users list) to update an existing admin user. It's a 2-step form that covers some of the same ground as Adding a New Admin User, with several differences called out below. There's no Permissions step and no Preview step here — permissions are changed separately, from the row actions menu — and the Update User button appears at the bottom of every step here, not just the last one, so you can save your changes as soon as you're done.

**Step 1 of 2 — User Details.**

| Field | What it means |
| --- | --- |
| Profile Picture | Upload or change this admin user's picture. Not part of the Add wizard. |
| User Name | Editable here — change it and the field re-checks that the new name isn't already taken by someone else. |
| Display Name / Email Address / Phone Number | Same as Step 1 of Adding a New Admin User. |
| User Active | Same toggle as adding — turn it on to allow this admin user to log in, or off to disable their account. |

> **Note:** There's no Password field on this screen — you can't change an admin user's password here. Use Change Password from the row actions menu on the Users list instead. Likewise, permissions aren't part of this wizard at all — use Change Permissions from the same menu to update what this admin user can see and do.
