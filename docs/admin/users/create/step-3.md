### Step 3 of 4 — Additional Details

Everything on this step is optional except Timezone.

![Step 3: Additional Details.](../../images/admin-user-step3-additional.png)

_Step 3: Additional Details._

| Field                                            | What it means                                                                   |
| ------------------------------------------------ | ------------------------------------------------------------------------------- |
| First Name / Last Name                           | This person's name.                                                             |
| Alternate Email                                  | A backup email address for this admin user.                                     |
| Timezone                                         | Required — the timezone this admin user's activity and timestamps are shown in. |
| Locale                                           | The display language.                                                           |
| Address, City, State/Province, Country, Zip Code | This admin user's postal address.                                               |
