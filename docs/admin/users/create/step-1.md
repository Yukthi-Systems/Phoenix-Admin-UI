### Adding a New Admin User

Click Create (top right of the Users list) to start. You'll fill in 4 steps, and can click Previous at any point to go back and fix something.

### Step 1 of 4 — User Details

![Step 1: User Details.](../../images/admin-user-step1-details.png)

*Step 1: User Details.*

| Field | What it means |
| --- | --- |
| User Name | A unique login username for this person. It can't be changed later, so choose carefully. |
| Display Name | The name shown for this person around the panel. |
| Email Address | Their email address. |
| Phone Number | Their phone number, with the country code picked from the flag dropdown. |
| Password / Confirm Password | Set an initial login password for this admin user. |
| User Active | Turned on by default — the account can log in immediately. Turn it off to set it up now and enable it later. |

> **Note:** Username Requirements: the username must be unique and cannot be changed after the account is created. It can only contain letters, numbers, hyphens (-) and underscores (_) — no spaces or other special characters.
