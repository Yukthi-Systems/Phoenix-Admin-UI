# 11. Admin

The Admin menu controls who can log into this panel and what they're allowed to do once they're in. It has two screens: Users and Permission Templates.

Where to find it: click Admin in the left menu, then Users or Permission Templates.

## 11.1 Users

An admin user is a person who can log into this panel — separate from a mailbox or identity, which is about email. Each admin user gets their own login and their own set of permissions.
