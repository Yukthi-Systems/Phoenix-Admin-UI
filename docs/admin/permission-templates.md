## 11.2 Permission Templates

A permission template is a saved, reusable set of permissions — build it once here, then apply it to a new admin user in one click using the Load Permission Template dropdown you saw in section 11.1's Permissions step, instead of ticking everything by hand every time.

Where to find it: click Admin in the left menu, then Permission Templates.

### Adding a New Permission Template

Click Add Permission Template. Give the template a name, then tick permissions using the exact same categories, actions and matrix covered in section 11.1's Step 2 of 4 — Permissions (Admin Management, User Management, CRM, Server Management, Logs, All Policies & Restrictions, Session Management and Admin User Security Management), including the View/Create/Edit/Delete columns, the dash (—) for actions that don't apply, and each category's own Select all button.

> **Note:** The template name can only contain letters, numbers, spaces, hyphens (-) and underscores (_) — other special characters aren't allowed. Once saved, the template appears as an option in the Load Permission Template dropdown whenever you or another admin creates a new admin user.
