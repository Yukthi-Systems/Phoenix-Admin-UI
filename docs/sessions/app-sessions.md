## 10.2 Mail 25 App

This screen shows active sessions from the Mail 25 mobile app.

| Field          | What it means                                 |
| -------------- | --------------------------------------------- |
| Email          | The identity signed in on that device.        |
| Phone No       | The phone number associated with the session. |
| Device         | The device the app is running on.             |
| Session ID     | The unique ID for that session.               |
| Last Active At | When the session was last active.             |
