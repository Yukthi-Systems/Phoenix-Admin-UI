## 10.3 SSO

This screen shows single sign-on sessions for the domain selected at the top right. Pick a domain from the dropdown to see its SSO sessions.

| Field                 | What it means                                         |
| --------------------- | ----------------------------------------------------- |
| Email                 | The identity signed in.                               |
| Status                | Whether the session is currently active.              |
| Device / Browser      | The device and browser the session was created from.  |
| IP Address            | The IP address the session was created from.          |
| Created At            | When the session was first created.                   |
| Last Authenticated At | When the identity last authenticated in this session. |
