## 9.3 Email Login Attempts Logs

This screen records login attempts made against email accounts — useful for spotting repeated failed logins or checking logins from a specific address.

Where to find it: click Logs in the left menu, then Email Login Attempts.

![The Login Attempts Logs screen.](../images/logs-login-attempts.png)

_The Login Attempts Logs screen._

| Field      | What it means                                                   |
| ---------- | --------------------------------------------------------------- |
| Email Id   | Filter by the email address the login attempt was made against. |
| IP Address | Filter by the IP address the attempt came from.                 |
| Domain     | Required — the domain to search within.                         |
| Date Range | Required — the period of time to search within.                 |

Click Submit to run the search, or Clear Filters to reset everything.
