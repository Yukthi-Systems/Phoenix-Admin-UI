## 9.2 Mail Flow Logs

Mail Flow Logs record individual emails that passed through the system — useful for checking whether a specific email was sent, received, or blocked.

Where to find it: click Logs in the left menu, then Mail Flow.

![The Mail Flow Logs screen.](../images/logs-mailflow.png)

*The Mail Flow Logs screen.*

| Field | What it means |
| --- | --- |
| Domain | Required — pick the domain whose mail flow you want to look at. No results are shown until you select one. |
| Subject | Filter by the email's subject line. |
| From Email Id | Filter by the sender's address. |
| Log Status | Filter by the outcome of the email, e.g. delivered or blocked. |
| Log Type | Filter by the type of log entry. |
| EUID | Filter by the email's unique ID, if you already know it. |
| To Email IDs (comma separated) | Filter by one or more recipient addresses, separated by commas. |
| Date Range | Required — the period of time to search within. |

Click Search Logs to run the search, or Clear Filters to reset everything.

> **Note:** You must pick a domain before any results appear — the screen shows "Please Select a Domain" until you do.
