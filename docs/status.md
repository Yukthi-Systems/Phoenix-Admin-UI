# 12. System Status

System Status shows whether Phoenix's own services are running normally, and lists any maintenance or incidents, past or upcoming.

Where to find it: click System Status in the left menu. Click Refresh (top right) at any time to get the latest status.

## 12.1 Current Status

This tab shows the live status right now.

![The System Status screen, Current Status tab.](images/system-status-current.png)

*The System Status screen, Current Status tab.*

| Field | What it means |
| --- | --- |
| All Systems Operational | Shown in green when every service is running smoothly. If something is affected, this banner changes to reflect it. |
| No active or upcoming status updates at this time | Shown when there's no maintenance or incident to report. When there is one, it's listed here instead. |

## 12.2 All Updates

This tab shows the full history of status updates — past maintenance windows and any incidents that were reported, not just what's happening right now.
