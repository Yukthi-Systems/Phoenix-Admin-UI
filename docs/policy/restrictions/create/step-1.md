### Adding a New Restriction Policy

Click Add Single Restriction Policy. You'll fill in 3 steps, and can click Previous at any point to go back and fix something.

### Step 1 of 3 — Policy Information

![Step 1: Policy Information.](../../images/policy-restriction-step1-info.png)

_Step 1: Policy Information._

| Field         | What it means                                                                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Policy Name   | A name for this policy, so you can recognize it in the list and when picking it elsewhere (e.g. as an identity's Restriction Policy in section 4.5.4). |
| Description   | Optional — a short note about what this policy is for.                                                                                                 |
| Policy Active | Turned on by default — the policy applies as soon as you create it. Turn it off to set it up now and turn it on later.                                 |
