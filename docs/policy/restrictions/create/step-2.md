### Step 2 of 3 — Restrictions

![Step 2: Access Restrictions.](../../images/policy-restriction-step2-restrictions.png)

_Step 2: Access Restrictions._

Both fields are optional, and work independently — you can set one, both, or neither.

| Field        | What it means                                                                                                                                               |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Geo Location | Pick a country or region from the dropdown and click Add to restrict access based on where the connection is coming from. You can add more than one.        |
| IP Address   | Type an IP address, choose its subnet size from the dropdown next to it (e.g. 24), and click Add to restrict access by IP range. You can add more than one. |
