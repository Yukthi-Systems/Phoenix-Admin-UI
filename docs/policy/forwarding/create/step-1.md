### Adding a New Forwarding Policy

Click Add Single Forwarding Policy. You'll fill in 3 steps, and can click Previous at any point to go back and fix something.

### Step 1 of 3 — Policy Information

![Step 1: Policy Information.](../../images/policy-forwarding-step1-info.png)

_Step 1: Policy Information._

| Field         | What it means                                                                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Domain        | The domain this policy belongs to — this is set to the domain you currently have selected and can't be changed here.                              |
| Policy Name   | A name for this policy, so you can recognize it in the list and when picking it elsewhere (e.g. as a mailbox's Forwarding Policy in section 5.4). |
| Description   | Optional — a short note about what this policy is for.                                                                                            |
| Policy Active | Turned on by default — the policy applies as soon as you create it. Turn it off to set it up now and turn it on later.                            |
