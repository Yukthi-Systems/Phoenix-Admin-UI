### Adding a New Attachment Policy

Click Add Single Policy. You'll fill in 3 steps, and can click Previous at any point to go back and fix something.

### Step 1 of 3 — Policy Details

![Step 1: Policy Details.](../../images/policy-attachment-step1-details.png)

*Step 1: Policy Details.*

| Field | What it means |
| --- | --- |
| Domain | The domain this policy belongs to — this is set to the domain you currently have selected and can't be changed here. |
| Policy Name | A name for this policy, so you can recognize it in the list. |
| Policy Description | Optional — a short note about what this policy is for. |
| Set Size Limit | Turn this on to restrict how large an attachment can be. Turned off, attachments of any size are allowed (subject to your mail server's own limits). |
| Maximum Attachment Size (MB) | Only shown when the toggle above is on — the largest single attachment allowed, in megabytes. This applies per file, not to the whole email. |
| Policy Active | Turned on by default — the policy applies as soon as you create it. Turn it off to set it up now and turn it on later. |
