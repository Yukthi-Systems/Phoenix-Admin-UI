### Step 2 of 3 — File Types

![Step 2: File Type Configuration.](../../images/policy-attachment-step2-filetypes.png)

*Step 2: File Type Configuration.*

| Field | What it means |
| --- | --- |
| Allowed Extensions | File types that are always let through. Type an extension and press Enter or comma to add it, or drag one over from the Blocked list. |
| Blocked Extensions | File types that are always rejected. A long list of commonly dangerous extensions (like .exe and .bat) is blocked by default for security — you can add more, but the pre-blocked ones can only be removed by dragging them into Allowed, not deleted outright. |

> **Note:** Extensions are automatically lower-cased and stripped of their leading dot when you add them, so "PDF" and ".pdf" both become "pdf".
