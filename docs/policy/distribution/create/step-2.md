### Step 2 of 3 — Additional

![Step 2: Group Members.](../../images/policy-distribution-step2-additional.png)

*Step 2: Group Members.*

| Field | What it means |
| --- | --- |
| Rule Type | Who is allowed to send mail to this group: Anyone can send mail to this mailbox; Any member of the group can send emails to the group's mailboxes; Anyone within the domain is allowed to send emails; or Specific users can send mail to this mailbox. |
| Internal Members | Pick existing mailboxes from the dropdown to add as group members. Only shown when Rule Type needs a member list. |
| External Members | Outside email addresses to add as group members. Type an address and click Add. |

> **Note:** Internal and External Members only need entries if you're building the group's member list — Rule Type on its own already controls who can send mail to it.
