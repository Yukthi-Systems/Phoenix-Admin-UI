# 8. Policies

Policies are rules you create once and then apply to domains and identities elsewhere in the panel — for example the Restriction Policy dropdown you saw in section 4.5.4. The Policies menu has several kinds: General, Filters, Attachment, Forwarding, Distribution, Restrictions, Caution and Disclaimer.

Where to find it: click Policies in the left menu, then the kind of policy you want.

> **Note:** Every Policy Name, Caution Message Name and Disclaimer Name field in this chapter only accepts letters, numbers, spaces, hyphens (-) and underscores (\_) — other special characters aren't allowed.

## 8.1 General Policies

This page lists every general policy you've created, for the domain selected at the top right.

![The General Policies list.](../images/policy-general-list.png)

_The General Policies list._

| Field                   | What it means                                                    |
| ----------------------- | ---------------------------------------------------------------- |
| Policy Name             | Click it to open the policy's details.                           |
| Status                  | Active or turned off.                                            |
| Created At / Updated At | When the policy was first created, and when it was last changed. |

### The Row Actions Menu

Click the ⋮ (three dots) at the end of any policy's row:

![The row actions menu on a general policy.](../images/policy-general-row-menu.png)

_The row actions menu on a general policy._

| Field         | What it means                                                                                    |
| ------------- | ------------------------------------------------------------------------------------------------ |
| Edit Policy   | Change this policy's settings.                                                                   |
| Copy Policy   | Create a new policy with the same settings as this one, so you don't have to start from scratch. |
| Delete Policy | Permanently removes the policy. This cannot be undone, so use it carefully.                      |

### The Actions Menu (Bulk Tools)

Click the Actions button (top right) for ways to work with policies in bulk:

![The Actions menu.](../images/policy-general-actions-menu.png)

_The Actions menu._

| Field             | What it means                                                                                                     |
| ----------------- | ----------------------------------------------------------------------------------------------------------------- |
| Add Single Policy | Create one general policy — opens the same 3-step wizard covered below.                                           |
| Import            | Upload a file to create multiple policies at once, instead of one by one.                                         |
| Bulk Edit         | Export your policies to a file, make your changes in it, then re-upload it to update multiple policies in one go. |
| Export            | Download all your policies as an Excel file.                                                                      |
