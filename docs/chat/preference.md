## 6.2 Chat Preference

This page sets the chat rules for everyone in your organization. Changes take effect immediately after saving, and turning a feature off blocks it everywhere, on every device.

![The Chat Preference screen.](../images/chat-preference.png)

_The Chat Preference screen._

| Field                       | What it means                                                                                                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Enable Direct Chat          | Lets users send private one-on-one messages. Turned off, users can only chat through groups or channels.                                 |
| Enable Group & Channel Chat | Lets users create and join group conversations and channels. Turned off, all multi-user chat is blocked.                                 |
| Enable File Sharing         | Lets users attach and share files inside chat messages. Turned off, all file uploads and downloads in chat are blocked.                  |
| Per-File Size Limit (MB)    | The largest single file users are allowed to share in chat. Larger files are rejected.                                                   |
| Total Allocated Quota (GB)  | The total storage space available for all chat files across your organization. Change it and click Update Quota to save just this value. |

The panel on the right, Current Configuration, is a live summary of what's turned on right now, plus a tip explaining what happens if you turn off Direct Chat.

> **Note:** These three toggles and the two size fields are saved together — click Save Preferences (top right) after making your changes, not just Update Quota.
