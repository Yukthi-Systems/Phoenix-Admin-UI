## 7.2 File Service Preference

This page sets the file storage rules for everyone in your organization. Changes take effect immediately after saving; storage quotas for individual identities are set separately on the File Users page.

![The File Service Preference screen.](../images/file-service-preference.png)

_The File Service Preference screen._

| Field                  | What it means                                                                                                                 |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Enable File Sharing    | Lets users share their uploaded files with other identities. Turned off, all file sharing across the organization is blocked. |
| Enable File Versioning | Keeps previous versions of a file whenever it's overwritten, so users can restore an earlier version.                         |

The panel on the right, Current Configuration, is a live summary of what's turned on right now, plus a tip reminding you that quotas are set per identity on the File Users page.

> **Note:** Click Save Preferences (top right) after changing either toggle.
