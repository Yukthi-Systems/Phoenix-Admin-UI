### Step 2 of 3 — Department Details

![Step 2: Department Details.](../../images/dept-step2-details.png)

_Step 2: Department Details._

Everything on this step is optional.

| Field              | What it means                                                                                                                                                                    |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Address            | A physical address for the department, if it has one.                                                                                                                            |
| Description        | A short line describing what this department does.                                                                                                                               |
| Notes              | Anything else worth remembering about this department.                                                                                                                           |
| Authorized Persons | People who can manage or represent this department. Click + Add Person and fill in their Name, Email and Phone (pick the correct country code first). You can add more than one. |
