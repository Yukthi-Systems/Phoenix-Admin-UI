## 8.7 Caution Management

A caution is a warning message shown to people before they can proceed with something risky — for example, a heads-up banner on an email from outside your organization.

Where to find it: click Policies in the left menu, then Caution.

This page lists every caution message you've created.

![The Caution Management list.](../images/caution-list.png)

_The Caution Management list._

| Field                       | What it means                                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Caution Name                | Click it to open the caution's details.                                                                       |
| Domain Name                 | The domain this caution applies to. Shows -- when it applies more broadly rather than to one specific domain. |
| Status                      | Active or turned off.                                                                                         |
| Created Date / Updated Date | When the caution was first created, and when it was last changed.                                             |

### The Row Actions Menu

Click the ⋮ (three dots) at the end of any caution's row:

![The row actions menu on a caution.](../images/caution-row-menu.png)

_The row actions menu on a caution._

| Field          | What it means                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------- |
| Edit Caution   | Change this caution's settings.                                                                   |
| Copy Caution   | Create a new caution with the same settings as this one, so you don't have to start from scratch. |
| Delete Caution | Permanently removes the caution. This cannot be undone, so use it carefully.                      |

### The Actions Menu (Bulk Tools)

Click the Actions button (top right) for ways to work with cautions in bulk:

![The Actions menu.](../images/caution-actions-menu.png)

_The Actions menu._

| Field              | What it means                                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| Add Single Caution | Create one caution message — opens the same 3-step wizard covered below.                                |
| Import             | Upload a file to create multiple cautions at once, instead of one by one.                               |
| Bulk Edit          | Export your cautions to a file, make your changes in it, then re-upload it to update multiple cautions. |
| Export             | Download all your cautions as an Excel file.                                                            |
