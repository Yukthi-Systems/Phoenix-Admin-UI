# 4. Identity Management

Identity Management is a menu with two sections: Domains (the domains your organization sends and receives mail from) and Identities (individual mailboxes). This chapter covers both, starting with Domains.

Where to find it: click Identity Management in the left menu, then Domains or Identities.

## 4.1 The Domains List

This page lists every domain you manage, whether it's Active and whether its DNS Verification is Verified — a domain must be verified before it can be used.

![The Domains list.](../images/domain-list.png)

*The Domains list.*

- Click a domain's name to open it.
- Tick the checkbox next to one or more domains to select them for a bulk action.
## 4.2 The Row Actions Menu

Click the ⋮ (three dots) at the end of any domain's row:

![The row actions menu on a domain.](../images/domain-row-menu.png)

*The row actions menu on a domain.*

| Field | What it means |
| --- | --- |
| Edit Domain | Change this domain's settings — see below. |
| View DNS Records | See the DNS records this domain needs (for example, the verification record). |
| Move Domain | Move this domain to a different organization. |
| Deactivate | Turns the domain off. It's kept, but mail for it stops working until you activate it again. |
| Delete Domain | Permanently removes the domain. This cannot be undone, so use it carefully. |

## 4.3 The Actions Menu (Bulk Tools)

Click the Actions button (top right) for ways to work with domains in bulk:

![The Actions menu.](../images/domain-actions-menu.png)

*The Actions menu.*

| Field | What it means |
| --- | --- |
| Add Single Domain | Create one domain — opens the same 5-step wizard covered in section 4.4 below. |
| Bulk Import | Upload a file to create multiple domains at once, instead of one by one. |
| Bulk Edit | Export your domains to a file, make your changes in it, then re-upload it to update multiple domains in one go. |
| Export | Download all your domains as an Excel file. |
