## 8.8 Disclaimer Management

A disclaimer is a standard notice — for example a legal or confidentiality notice — that you can attach to outgoing mail.

Where to find it: click Policies in the left menu, then Disclaimer.

This page lists every disclaimer you've created.

![The Disclaimer Management list.](../images/disclaimer-list.png)

_The Disclaimer Management list._

| Field                       | What it means                                                        |
| --------------------------- | -------------------------------------------------------------------- |
| Disclaimer Name             | Click it to open the disclaimer's details.                           |
| Created Date / Updated Date | When the disclaimer was first created, and when it was last changed. |

### The Row Actions Menu

Click the ⋮ (three dots) at the end of any disclaimer's row:

![The row actions menu on a disclaimer.](../images/disclaimer-row-menu.png)

_The row actions menu on a disclaimer._

| Field             | What it means                                                                                        |
| ----------------- | ---------------------------------------------------------------------------------------------------- |
| Edit Disclaimer   | Change this disclaimer's settings.                                                                   |
| Copy Disclaimer   | Create a new disclaimer with the same settings as this one, so you don't have to start from scratch. |
| Delete Disclaimer | Permanently removes the disclaimer. This cannot be undone, so use it carefully.                      |

### The Actions Menu (Bulk Tools)

Click the Actions button (top right) for ways to work with disclaimers in bulk:

![The Actions menu.](../images/disclaimer-actions-menu.png)

_The Actions menu._

| Field                 | What it means                                                                                                 |
| --------------------- | ------------------------------------------------------------------------------------------------------------- |
| Add Single Disclaimer | Create one disclaimer — opens the same 3-step wizard covered below.                                           |
| Import                | Upload a file to create multiple disclaimers at once, instead of one by one.                                  |
| Bulk Edit             | Export your disclaimers to a file, make your changes in it, then re-upload it to update multiple disclaimers. |
| Export                | Download all your disclaimers as an Excel file.                                                               |
