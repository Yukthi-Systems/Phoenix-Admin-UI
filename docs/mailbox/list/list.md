# 5. Mailbox

A mailbox is what actually lets an identity send and receive email — it's added on top of an identity to give it inbox storage. This chapter covers the Mailbox screen.

Where to find it: click Mailbox in the left menu.

## 5.1 The Mailbox List

This page lists every mailbox that belongs to the domain currently selected at the top right.

![The Mailbox list.](../../images/mailbox-list.png)

*The Mailbox list.*

| Field | What it means |
| --- | --- |
| Email | The mailbox's email address. Click it to open its details. |
| Storage | How much space this mailbox has used out of its total allocation, shown as a bar, a percentage, and the exact amounts (e.g. "0.02 GB / 0.10 GB"). |
| Status | Active or turned off. |

## 5.2 The Row Actions Menu

Click the ⋮ (three dots) at the end of any mailbox's row:

![The row actions menu on a mailbox.](../../images/mailbox-row-menu.png)

*The row actions menu on a mailbox.*

| Field | What it means |
| --- | --- |
| Edit Mailbox | Change this mailbox's settings. |
| Manage Quota | Increase or decrease the storage space (GB) allocated to this mailbox. |
| Copy Mailbox | Create a new mailbox with the same settings as this one, so you don't have to start from scratch. |
| Sync via IMAP | Connect or refresh this mailbox's sync with an external mail client over IMAP. |
| Deactivate | Turns the mailbox off. It's kept, but it can't send or receive mail until you activate it again. |
| Delete Mailbox | Permanently removes the mailbox. This cannot be undone, so use it carefully. |

## 5.3 The Actions Menu (Bulk Tools)

Click the Actions button (top right) for ways to work with mailboxes in bulk:

![The Actions menu.](../../images/mailbox-actions-menu.png)

*The Actions menu.*

| Field | What it means |
| --- | --- |
| Add Single Mailbox | Create one mailbox — opens the same 3-step wizard covered in section 5.4 below. |
| Import | Upload a file to create multiple mailboxes at once, instead of one by one. |
| Bulk Edit | Export your mailboxes to a file, make your changes in it, then re-upload it to update multiple mailboxes in one go. |
| Export | Download all your mailboxes as an Excel file. |
