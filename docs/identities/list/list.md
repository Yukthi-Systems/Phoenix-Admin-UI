## 4.5 Identities

An identity is an individual mailbox account, e.g. john.doe@example.com. This section covers the Identities screen.

Where to find it: click Identity Management in the left menu, then Identities.

### 4.5.1 The Identities List

This page lists every identity that belongs to the domain currently selected at the top right.

![The Identities list.](../../images/identity-list.png)

*The Identities list.*

| Field | What it means |
| --- | --- |
| Email Identity | The identity's full email address. Click it to open its details. |
| Name | The person's name. |
| Phone Number | Their registered phone number. |
| Status | Active or turned off. |
| Mailbox / Chat / Files | Whether each service is Enabled or Not Provisioned (not turned on) for this identity. |

Click the domain name box (top right, next to Actions) to switch domains:

![Choosing which domain's identities to view.](../../images/identity-choose-domain.png)

*Choosing which domain's identities to view.*

> **Note:** Only one domain's identities are shown at a time — use Choose a domain to look at another domain.

### 4.5.2 The Row Actions Menu

Click the ⋮ (three dots) at the end of any identity's row:

![The row actions menu on an identity.](../../images/identity-row-menu.png)

*The row actions menu on an identity.*

| Field | What it means |
| --- | --- |
| Edit Identity | Change this identity's details. |
| Deactivate | Turns the identity off. It's kept, but it can't send or receive mail until you activate it again. |
| Change Password | Set a new password for this identity. |
| Delete Identity | Permanently removes the identity. This cannot be undone, so use it carefully. |

### 4.5.3 The Actions Menu (Bulk Tools)

Click the Actions button (top right) for ways to work with identities in bulk:

![The Actions menu.](../../images/identity-actions-menu.png)

*The Actions menu.*

| Field | What it means |
| --- | --- |
| Add Single | Create one identity — opens the same 4-step wizard covered in section 4.5.4 below. |
| Bulk Import | Upload a file to create multiple identities at once, instead of one by one. |
| Bulk Edit | Export your identities to a file, make your changes in it, then re-upload it to update multiple identities in one go. |
| Export | Download all your identities as an Excel file. |
