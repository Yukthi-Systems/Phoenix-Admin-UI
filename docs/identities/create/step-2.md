### Step 2 of 4 — Password

![Step 2: Password, with all three 2FA options turned on.](../../images/identity-step2-2fa-on.png)

_Step 2: Password, with all three 2FA options turned on._

| Field                       | What it means                                                                                                                                            |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Password / Confirm Password | Set a password for this identity. Both boxes must match.                                                                                                 |
| App 2FA Enabled             | When turned on, the user must download the Mail 25 App to receive their login codes (links to the App Store and Google Play are shown).                  |
| SMS 2FA Enabled             | When turned on, login codes are texted to the identity's Primary Phone Number.                                                                           |
| Email 2FA Enabled           | When turned on, login codes are sent to the Recovery / Secondary Email. A secondary email must already be set in Step 1, or you'll be warned to add one. |

> **Note:** All three 2FA options are off by default — turn on only the ones you want this identity to use, and you can turn on more than one at a time.
