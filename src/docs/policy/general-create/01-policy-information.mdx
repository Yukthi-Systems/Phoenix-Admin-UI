## Policy information

### Domain

The domain this policy belongs to. It is set to the domain you currently have
selected and cannot be changed here — switch domains on the policy list first
if you need a different one.

### Policy name

A name for this policy, so you can recognise it in the list and when picking it
elsewhere. It accepts letters, numbers, spaces, hyphens (`-`) and underscores
(`_`) only.

### Policy active

On by default, so the policy applies as soon as it is created. Turn it off to
set it up now and switch it on later.
