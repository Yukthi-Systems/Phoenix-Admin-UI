## Group members

### Rule type

Who is allowed to send mail to this group:

- **Anyone** can send mail to this mailbox.
- **Any member of the group** can send mail to the group's mailboxes.
- **Anyone within the domain** is allowed to send.
- **Specific users** can send mail to this mailbox.

### Internal members

Pick existing mailboxes from the dropdown to add as group members. Shown only
when the rule type needs a member list.

### External members

Outside email addresses to add as group members. Type an address and click
**Add**.

<Callout type="info">
  Members are only needed if you are building the group's member list — the rule
  type on its own already controls who may send mail to the group.
</Callout>
