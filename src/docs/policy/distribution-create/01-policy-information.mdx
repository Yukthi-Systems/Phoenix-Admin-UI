## Policy information

### Domain

The domain this policy belongs to. It is set to the domain you currently have
selected and cannot be changed here.

### Policy name

A name for this policy, so you can recognise it in the list and when picking it
as a mailbox's distribution policy. It accepts letters, numbers, spaces, hyphens
(`-`) and underscores (`_`) only.

### Description

Optional — a short note about what this policy is for.

### Policy active

On by default, so the policy applies as soon as it is created.
