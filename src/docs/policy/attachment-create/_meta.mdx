# Add an attachment policy

An attachment policy controls what people can email as an attachment — the
largest file size allowed, and which file types are allowed or blocked. The
wizard has three steps:

1. **Policy Details** — domain, name, description and size limit.
2. **File Types** — the allowed and blocked extension lists.
3. **Preview** — check everything, then create.

Open the **Guide** panel on any step to see help for just that step.
