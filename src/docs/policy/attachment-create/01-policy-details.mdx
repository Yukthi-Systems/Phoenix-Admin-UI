## Policy details

### Domain

The domain this policy belongs to. It is set to the domain you currently have
selected and cannot be changed here.

### Policy name

A name for this policy, so you can recognise it in the list. It accepts letters,
numbers, spaces, hyphens (`-`) and underscores (`_`) only.

### Policy description

Optional — a short note about what this policy is for.

### Set size limit

Turn this on to restrict how large an attachment can be. Left off, attachments
of any size are allowed, subject to your mail server's own limits.

### Maximum attachment size (MB)

Shown only when the toggle above is on. The largest single attachment allowed.

<Callout type="info">
  This limit applies **per file**, not to the total size of the email.
</Callout>

### Policy active

On by default, so the policy applies as soon as it is created.
