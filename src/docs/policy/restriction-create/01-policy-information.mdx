## Policy information

### Policy name

A name for this policy, so you can recognise it in the list and when picking it
as an identity's restriction policy. It accepts letters, numbers, spaces,
hyphens (`-`) and underscores (`_`) only.

### Description

Optional — a short note about what this policy is for.

### Policy active

On by default, so the policy applies as soon as it is created. Turn it off to
set it up now and switch it on later.
