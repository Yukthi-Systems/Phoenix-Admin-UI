## Content

This is the actual warning message people will see. Switch between the **Text**
and **HTML** tabs to choose how you write it, and use the **Desktop Preview**
panel on the right to see how it will look.

### Text content

Write the caution message as plain text, up to **400 characters**.

### HTML

Switch to this tab to write the message as HTML instead, for more formatting
control.

### Generate HTML with AI

Lets the panel generate HTML content for you instead of writing it by hand.

<Callout type="tip">
  Keep the wording short and specific — a caution people actually read beats a
  long one they learn to dismiss.
</Callout>
