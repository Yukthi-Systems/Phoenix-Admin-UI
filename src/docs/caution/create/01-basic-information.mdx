## Basic information

### Caution message name

A name for this caution, so you can recognise it in the list. It accepts
letters, numbers, spaces, hyphens (`-`) and underscores (`_`) only.

### Severity

How serious this caution is: **Low**, **Medium** or **High**.

### Description

A short explanation of what this caution is warning about.

### Notes

Optional — any additional notes for your own reference.
