## Branches

A branch is an office or location belonging to this organization. At least one
is required before you can continue — if you try to move on without one, the
panel reminds you to add a branch first.

### Branch name

A short name for the office, e.g. `Head Office` or `Mumbai Branch`.

### Address line 1 / 2

The street address. Line 1 is required; line 2 is for extra detail such as a
floor or building name.

### City, state, country, pincode

The rest of the address.

<Callout type="tip">
  Fill in the fields and click **+ Add Branch** to save the branch to the list
  below. Repeat for every office the organization has — you can add as many as
  you need before moving on.
</Callout>
