## Preview

Review the key name, description, any metadata tags, and the full list of
permissions you selected in the previous step. Go back to any step to make
changes before creating the key.

<Callout type="danger" title="Save the secret immediately">
  Once you click **Create API Key**, a confirmation dialog shows the key's
  secret value exactly once. Copy it or download the PDF straight away — closing
  the dialog without saving it means the secret is gone for good, and the only
  recovery is creating a new key.
</Callout>
