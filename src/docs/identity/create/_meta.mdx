# Add an identity

An identity is an individual account, e.g. `john.doe@example.com`. It is the
core record — mailbox, chat and file access are all added on top of it. The
wizard has four steps:

1. **Identity Info** — name, email address and phone number.
2. **Password** — the initial password and two-factor authentication options.
3. **Policies** — restriction policy, department, and which services to enable.
4. **Preview** — check everything, then create.

<Callout type="info" title="Identities belong to one domain">
  The identity is created under the domain currently selected at the top right
  of the Identities screen. Switch domains there before you start if you need a
  different one.
</Callout>

Open the **Guide** panel on any step to see help for just that step.
