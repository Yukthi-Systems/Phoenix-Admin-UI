## Password

### Password / confirm password

Set the identity's password. Both boxes must match.

### App 2FA

When enabled, the user must install the **Mail 25 App** to receive login codes.
Links to the App Store and Google Play are shown on the form.

### SMS 2FA

When enabled, login codes are texted to the **primary phone number** entered on
step 1.

### Email 2FA

When enabled, login codes are sent to the **recovery / secondary email**. That
address must already be set on step 1, or you will be warned to add one.

<Callout type="info">
  All three options are off by default. Turn on only the ones this identity
  should use — more than one can be active at the same time.
</Callout>
