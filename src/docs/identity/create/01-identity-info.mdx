## Identity info

### First name / last name

The person's name. First name is required.

### Email address

Type only the part before the `@` — the domain you selected is added
automatically.

### Primary phone number

Pick the correct country code, then type the number. This is required, and it
is where SMS login codes are sent if you turn on SMS 2FA in the next step.

### Recovery / secondary email

Optional in general, but **required** if you plan to turn on Email 2FA on the
next step.

<Callout type="tip">
  Set the recovery email now even if you are not enabling Email 2FA yet — it
  saves coming back to edit the identity later.
</Callout>

### Identity status

Turn this on to make the identity active and usable straight away.
