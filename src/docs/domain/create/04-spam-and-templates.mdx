## Spam &amp; templates

### Spam destination

What happens to a message classified as spam:

| Option | Behaviour |
| --- | --- |
| Inbox | Delivered to the main inbox |
| Spam | Moved to the Spam folder (if it exists) |
| Trash | Moved to Trash |
| Permanently Delete | Deleted with no recovery |
| Send Digest | Held and delivered as a scheduled summary |
| Custom Folder | Moved to a named folder — you must supply the **folder name** |

<Callout type="warning">
  **Permanently Delete** cannot be undone. Prefer **Spam** or **Custom Folder**
  unless you are certain.
</Callout>

The description field updates automatically to explain the selected option.

### Caution &amp; disclaimer templates

Optionally attach a caution banner and/or a disclaimer footer that will be
applied to mail for this domain. Both can be changed later from the domain's
Edit page.
