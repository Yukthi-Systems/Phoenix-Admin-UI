## Domain details

### Domain name

Enter the fully-qualified domain you want to manage, e.g. `example.com`. It is
stored in lower case. You cannot change the domain name after the domain is
created.

<Callout type="warning">
  The domain must be one you control the DNS for — you will need to add a `TXT`
  record to prove ownership before it can be activated.
</Callout>

### Anti-phishing secret code

A short phrase (4–20 characters) shown to your users inside genuine Mail 25
messages so they can tell real mail from phishing. Allowed characters: letters,
numbers, spaces, underscores (`_`) and hyphens (`-`).

### Description &amp; address

Optional free-text fields for your own reference — the description appears in
the domain list, the address is stored on the domain record.
