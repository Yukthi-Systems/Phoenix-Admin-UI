## Password properties

### Session timeout

How long a user's session stays valid without activity, from 30 minutes up to
12 hours. Shorter is more secure; longer is more convenient.

### Maximum password age

When **enabled**, users must change their password after a set number of days.
You also configure up to three **notify-before** values (in days) — users are
reminded that many days ahead of the expiry.

<Callout type="tip">
  Notify values are automatically sorted and de-duplicated. Leaving one blank
  simply means one fewer reminder.
</Callout>

When **disabled**, passwords never expire and no reminders are sent.
