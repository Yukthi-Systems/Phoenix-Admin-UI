# Edit a domain

The **Edit Domain** wizard updates a domain that already exists. It has four
steps — the same as creation, minus the review/DNS-verification step:

1. **Domain Details** — anti-phishing code, description, address.
2. **Domain Properties** — catch-all forwarding and hybrid (on-prem) routing.
3. **Password Properties** — session timeout and password-age policy.
4. **Spam &amp; Templates** — spam destination, caution / disclaimer templates,
   filter and attachment policies.

<Callout type="info" title="Changes apply on save">
  Unlike creating a domain, there is no re-verification step. Clicking
  **Update Domain** applies every change immediately.
</Callout>

Use the stepper at the top to jump straight to the section you need — you do
not have to walk through every step.
