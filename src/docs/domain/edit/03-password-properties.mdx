## Password properties

### Session timeout

How long a user's session stays valid without activity (30 minutes – 12 hours).

### Maximum password age

When **enabled**, users must change their password after **Max Password Age
(days)**. You can set up to three **Notify (days before expiry)** values —
users are reminded that many days ahead.

<Callout type="warning">
  Lowering the max age can force a large number of users to reset their
  password at their next login. Change it during a low-traffic window.
</Callout>

When **disabled**, existing passwords stop expiring and pending reminders are
cancelled.
