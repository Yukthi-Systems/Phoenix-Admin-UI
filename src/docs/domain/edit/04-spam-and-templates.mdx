## Spam &amp; templates

### Delete spam

A quick switch: when **enabled**, spam is permanently deleted regardless of the
destination below.

### Spam destination

Where a message classified as spam is delivered:

| Option | Behaviour |
| --- | --- |
| Inbox | Delivered normally |
| Spam | Moved to the Spam folder |
| Trash | Moved to Trash |
| Permanently Delete | Deleted, no recovery |
| Send Digest | Held and delivered as a scheduled summary |
| Custom Folder | Moved to a named folder — set **Folder Name** |

<Callout type="warning">
  **Permanently Delete** and **Delete Spam** cannot be undone — users never see
  those messages.
</Callout>

### Templates &amp; policies

Attach or change the domain's **caution** banner, **disclaimer** footer,
**filter policy** and **attachment policy**. Leaving a selector empty removes
that template from the domain.
