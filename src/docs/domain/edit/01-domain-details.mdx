## Domain details

The **domain name** identifies the domain and stays as it is. On this step you
update:

### Anti-phishing secret code

The phrase shown to your users in genuine Mail 25 messages. 4–20 characters;
letters, numbers, spaces, underscores (`_`) and hyphens (`-`).

<Callout type="warning">
  A new code takes effect immediately. Tell your users before you change it,
  otherwise legitimate mail will look suspicious to them.
</Callout>

### Description &amp; address

Free-text fields for your own reference. The description shows in the domain
list.
