# Add a mailbox

A mailbox is what lets an identity send and receive email — it is added on top
of an identity to give it inbox storage. The wizard has three steps:

1. **Mailbox Info** — which identity the mailbox belongs to, and its storage.
2. **Mail Policies** — optional general, forwarding or distribution policies.
3. **Preview** — check everything, then create.

<Callout type="info" title="The identity must exist first">
  You can only create a mailbox for an identity that already exists. Create the
  identity first, then come back here.
</Callout>

Open the **Guide** panel on any step to see help for just that step.
