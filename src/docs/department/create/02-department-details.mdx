## Department details

Everything on this step is optional — you can leave it all empty and still
create the department.

### Address

A physical address for the department, if it has one.

### Description

A short line describing what this department does.

### Notes

Anything else worth remembering about this department.

### Authorized persons

People who can manage or represent this department. Click **+ Add Person** and
fill in their name, email and phone — pick the correct country code first. You
can add more than one.
