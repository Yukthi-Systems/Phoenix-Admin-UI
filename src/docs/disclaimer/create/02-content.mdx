## Content

This is the actual text attached to mail. Switch between the **Text** and
**HTML** tabs to choose how you write it, and use the **Desktop Preview** panel
on the right to see how it will look.

### Text content

Write the disclaimer as plain text, up to **400 characters**.

### HTML

Switch to this tab to write the disclaimer as HTML instead, for more formatting
control.

### Generate HTML with AI

Lets the panel generate HTML content for you instead of writing it by hand.

<Callout type="warning">
  If your disclaimer has legal wording, get it confirmed by whoever is
  responsible for it before you attach it to a live domain.
</Callout>
