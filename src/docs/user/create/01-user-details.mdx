## User details

### User name

A unique login username for this person.

<Callout type="warning">
  The username cannot be changed after the account is created. It accepts
  letters, numbers, hyphens (`-`) and underscores (`_`) — no spaces or other
  special characters.
</Callout>

### Display name

The name shown for this person around the panel.

### Email address

Their email address.

### Phone number

Their phone number, with the country code picked from the flag dropdown.

### Password / confirm password

Set an initial login password for this admin user.

### User active

On by default, so the account can log in immediately. Turn it off to set the
account up now and enable it later.
