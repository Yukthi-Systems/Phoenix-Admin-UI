# Add an admin user

An admin user is a person who can log into this panel — separate from a mailbox
or identity, which is about email. Each admin user gets their own login and
their own set of permissions. The wizard has four steps:

1. **User Details** — username, display name, contact details and password.
2. **Permissions** — exactly what this user can see and do.
3. **Additional Details** — name, timezone, locale and address.
4. **Preview** — check everything, then create.

<Callout type="warning" title="Permissions decide what they can reach">
  A new admin user has no access until you grant it on step 2. Grant only what
  the person actually needs — especially the permissions marked
  **(Sensitive)**, which control other admin users' logins and security.
</Callout>

Open the **Guide** panel on any step to see help for just that step.
