## Additional details

Everything on this step is optional except **timezone**.

### First name / last name

This person's name.

### Alternate email

A backup email address for this admin user.

### Timezone

Required. The timezone this admin user's activity and timestamps are shown in.

### Locale

The display language for this user.

### Address, city, state/province, country, zip code

This admin user's postal address.
